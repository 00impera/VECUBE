## ⬡ Overview

veCUBE is a fully on-chain rewards dashboard built on **Monad Mainnet (Chain ID: 143)**.  
Users who hold CubeNFTs and have registered vaults can claim staking rewards in two tokens — **CUBE** and **BMC** — at the end of each epoch.
